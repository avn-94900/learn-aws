# 7.1 Encryption and Key Management

## 1) What is AWS Key Management Service (KMS), and how is it used?

### What it is

AWS Key Management Service (KMS) is a service used to **create, store, and manage encryption keys** that protect data in AWS.

Instead of handling encryption keys yourself, AWS manages them securely.

---

### Why KMS is Important

Encryption without key management is risky.

Problems without KMS:

* Keys stored in code (security risk)
* Hard to rotate keys
* Difficult to audit key usage

KMS solves these issues by:

* Secure key storage
* Key rotation
* Access control using IAM
* Logging key usage

---

### How KMS is Used (Real Flow)

Typical usage:

```text
Application → Request encryption
              ↓
             KMS
              ↓
        Data encrypted
              ↓
      Store encrypted data
```

Used together with services like:

* Amazon S3
* Amazon RDS
* Amazon EBS

Example:

* Store encrypted files in S3
* Encrypt database storage
* Encrypt backups

---

### Types of Keys in KMS

| Key Type                    | Description                    | Use Case                  |
| --------------------------- | ------------------------------ | ------------------------- |
| AWS Managed Keys            | Created automatically by AWS   | Default encryption        |
| Customer Managed Keys (CMK) | Created and controlled by user | Custom security policies  |
| Customer Provided Keys      | Imported into KMS              | External compliance needs |

---

### Strong Interview Answer

**AWS KMS is a managed service used to create and control encryption keys. It integrates with AWS services to encrypt data at rest and in transit, supports key rotation, and provides audit logs for security tracking.**

---

## 2) What encryption types are supported by AWS KMS?

This question tests **basic cryptography knowledge** in AWS context.

---

### Encryption Types Supported

#### 1) Symmetric Encryption (Most Common)

Algorithm used:

* **AES-256**

Used for:

* Encrypting data
* Fast performance
* Most AWS services use this

Example:

* Encrypting S3 objects
* Encrypting database storage

---

#### 2) Asymmetric Encryption

Uses:

* Public key
* Private key

Algorithms:

* RSA
* ECC (Elliptic Curve Cryptography)

Used for:

* Secure data sharing
* Digital signatures

Example:

```text
Public Key → Encrypt
Private Key → Decrypt
```

---

#### 3) Envelope Encryption (Very Important Concept)

Most real AWS encryption uses this.

How it works:

```text
Data → Encrypted using Data Key
Data Key → Encrypted using KMS Key
```

Why this matters:

* Faster encryption
* Better scalability
* Strong security

---

### Strong Interview Answer

**AWS KMS supports symmetric encryption using AES-256, asymmetric encryption using RSA or ECC keys, and envelope encryption where data keys are encrypted using master keys managed by KMS.**

# 7.2 Threat Detection and Protection

---

## 3) What is AWS Shield, and how does it protect against attacks?

### What it is

AWS Shield protects applications from **Distributed Denial of Service (DDoS)** attacks.

DDoS attack means:

Attackers send **huge traffic** to crash systems.

---

### Types of AWS Shield

| Type            | Description                   | Cost |
| --------------- | ----------------------------- | ---- |
| Shield Standard | Basic automatic protection    | Free |
| Shield Advanced | Advanced protection + support | Paid |

---

### How It Protects Systems

AWS Shield:

* Detects abnormal traffic
* Filters malicious traffic
* Allows normal users
* Protects AWS edge services

Works with:

* Amazon CloudFront
* Elastic Load Balancing
* Amazon Route 53

---

### Real Attack Scenario

Without Shield:

```text
Internet → Huge fake traffic → Server crash
```

With Shield:

```text
Internet → Filter attack traffic → Server stays alive
```

---

### Strong Interview Answer

**AWS Shield is a DDoS protection service that detects and blocks malicious traffic targeting AWS resources. Shield Standard provides automatic protection, while Shield Advanced offers enhanced detection, monitoring, and response capabilities.**

---

## 4) What is Amazon GuardDuty, and how does it detect threats?

### What it is

Amazon GuardDuty is a **threat detection service** that monitors AWS accounts for suspicious activity.

---

### How GuardDuty Detects Threats

GuardDuty analyzes logs from:

* AWS CloudTrail
* Amazon VPC Flow Logs
* Amazon DNS Logs

It uses:

* Machine learning
* Threat intelligence
* Behavior analysis

---

### Example Threats Detected

GuardDuty detects:

* Unauthorized API calls
* Crypto mining attacks
* Suspicious IP communication
* Data exfiltration

Example:

```text
Unknown IP → Access attempt → GuardDuty alert
```

---

### Strong Interview Answer

**Amazon GuardDuty is a managed threat detection service that continuously monitors AWS logs and network traffic to identify suspicious activities such as unauthorized access, compromised instances, and malicious communication.**

---

## 5) What is AWS WAF, and how does it protect web applications?

### What it is

AWS WAF protects web applications from **common web attacks**.

WAF stands for:

**Web Application Firewall**

---

### Types of Attacks It Blocks

Common web attacks:

* SQL Injection
* Cross-Site Scripting (XSS)
* Bot attacks
* Malicious requests

---

### How AWS WAF Works

WAF uses:

**Rules**

Example rule:

```text
IF request contains SQL pattern
THEN block request
```

WAF is commonly attached to:

* Amazon CloudFront
* Application Load Balancer
* Amazon API Gateway

---

### Real Example

```text
User → Web App
        ↓
       WAF
        ↓
Allow or Block request
```

---

### Strong Interview Answer

**AWS WAF is a web application firewall that filters HTTP requests based on defined security rules. It protects applications from attacks such as SQL injection, cross-site scripting, and malicious bots.**

---

## 6) What is Amazon Inspector, and what vulnerabilities does it detect?

### What it is

Amazon Inspector scans workloads to find **security vulnerabilities**.

---

### What It Scans

Amazon Inspector scans:

* EC2 instances
* Container images
* Application dependencies

Used with:

* Amazon EC2
* Amazon ECR

---

### Types of Vulnerabilities Detected

Inspector detects:

#### 1) Missing Security Patches

Example:

```text
Old OS → Known vulnerability → Alert generated
```

---

#### 2) Software Vulnerabilities (CVEs)

CVE means:

Common Vulnerabilities and Exposures.

Example:

* Outdated libraries
* Vulnerable packages

---

#### 3) Network Exposure Risks

Example:

```text
Port 22 open to internet → Risk alert
```

---

### Real Workflow

```text
EC2 Instance → Inspector Scan → Vulnerability Report
```

---

### Strong Interview Answer

**Amazon Inspector is a vulnerability assessment service that scans EC2 instances and container images to detect security risks such as missing patches, exposed ports, and vulnerable software packages.**
