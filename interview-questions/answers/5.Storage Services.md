
# **5. Storage Services**

# **5.1 Storage Fundamentals**

## **What is the difference between Blob Storage and Object Storage?**

**Short Answer:**
Blob storage is a type of object storage designed mainly for large unstructured data like images and videos. Object storage is the broader concept used to store data as objects instead of files or blocks.

| Feature          | Blob Storage                 | Object Storage                 |
| ---------------- | ---------------------------- | ------------------------------ |
| Definition       | A type of object storage     | General storage model          |
| Data structure   | Binary Large Objects (BLOBs) | Objects with metadata          |
| Metadata support | Limited                      | Rich metadata                  |
| Typical use      | Media files, backups         | Logs, images, videos, archives |
| Example          | Blob in Azure                | Amazon S3                      |

**Interview Tip:**
Most real-world cloud systems use **Object Storage**, and blob storage is just one implementation style.

---

## **How does Amazon S3 store data internally?**

**Short Answer:**
Amazon S3 stores data as objects inside buckets and automatically replicates data across multiple storage devices in multiple Availability Zones.

**Detailed Explanation:**

In **Amazon S3**, data is stored as:

* **Bucket** → Container for objects
* **Object** → File + metadata
* **Key** → Unique object name

**Internal Behavior:**

* Objects stored across **multiple devices**
* Data replicated across **multiple Availability Zones**
* Designed for **11 nines durability (99.999999999%)**
* Uses distributed storage architecture
* Automatically handles failures

**Interview Answer:**
"Amazon S3 stores data as objects inside buckets. Each object includes data, metadata, and a unique key. Internally, S3 replicates objects across multiple devices and Availability Zones to provide high durability and availability."

---

## **What are the different storage classes in S3, and when should each be used?**

| Storage Class                     | When to Use                | Key Benefit                 |
| --------------------------------- | -------------------------- | --------------------------- |
| **S3 Standard**                   | Frequently accessed data   | High availability           |
| **S3 Intelligent-Tiering**        | Unknown access patterns    | Automatic cost optimization |
| **S3 Standard-IA**                | Infrequently accessed data | Lower storage cost          |
| **S3 One Zone-IA**                | Non-critical backups       | Cheapest IA storage         |
| **S3 Glacier Instant Retrieval**  | Rare but quick access      | Low-cost archive            |
| **S3 Glacier Flexible Retrieval** | Archive data               | Very low cost               |
| **S3 Glacier Deep Archive**       | Long-term archives         | Lowest cost                 |

All belong to:
**Amazon S3**

**Interview Tip:**
If unsure which class to choose → use **Intelligent-Tiering**.

---

## **How do you decide which storage service or storage class to use?**

**Decision Factors:**

| Factor              | Why It Matters            |
| ------------------- | ------------------------- |
| Access frequency    | Frequent vs rare access   |
| Latency requirement | Milliseconds vs hours     |
| Durability          | Business critical data    |
| Cost sensitivity    | Storage vs retrieval cost |
| Data size           | Small vs large files      |

**Simple Decision Flow:**

* **Frequently accessed →** S3 Standard
* **Rare access →** Glacier
* **Block storage →** EBS
* **Shared file system →** EFS

# **5.3 S3 Advanced Features**

## **What is S3 lifecycle management, and how does it reduce storage costs?**

**Short Answer:**
Lifecycle management automatically moves or deletes objects based on rules to reduce storage costs.

Works in:
**Amazon S3**

**Example Lifecycle Rule:**

* Day 0 → S3 Standard
* Day 30 → Move to Standard-IA
* Day 90 → Move to Glacier
* Day 365 → Delete

**Why It Saves Cost:**

* Moves data to **cheaper storage classes**
* Deletes unused data automatically

**Interview Answer:**
"S3 lifecycle management automates moving objects between storage classes or deleting them after a defined time, helping reduce long-term storage costs."

---

## **What is S3 Cross-Region Replication (CRR), and when should it be used?**

**Short Answer:**
CRR automatically copies objects from one AWS region to another.

Used in:
**Amazon S3**

**When to Use CRR:**

* Disaster recovery
* Multi-region applications
* Compliance requirements
* Global users

**Important Requirement:**

* Versioning must be enabled

---

## **What is S3 Transfer Acceleration, and when should it be used?**

**Short Answer:**
Transfer Acceleration speeds up uploads and downloads to S3 using AWS edge locations.

Used in:
**Amazon S3**

**When to Use:**

* Uploading large files
* Users located far from AWS region
* Global applications

**How It Works:**

Uses the global network of
**Amazon CloudFront** edge locations.

---

## **How do you secure data at rest in S3, including encryption options?**

**Short Answer:**
Use encryption to protect stored data using AWS-managed or customer-managed keys.

Encryption Options:

| Encryption Type        | Description            |
| ---------------------- | ---------------------- |
| SSE-S3                 | AWS manages keys       |
| SSE-KMS                | Uses KMS-managed keys  |
| SSE-C                  | Customer-provided keys |
| Client-side encryption | Encrypt before upload  |

Uses:
**AWS Key Management Service (KMS)**

**Best Practice:**
Use **SSE-KMS** for sensitive data.

---

## **How do you manage public access control for S3 objects?**

**Short Answer:**
Use bucket policies, IAM policies, ACLs, and Block Public Access settings.

Security Controls:

| Method              | Purpose                     |
| ------------------- | --------------------------- |
| IAM Policies        | Control user access         |
| Bucket Policies     | Control bucket-level access |
| ACLs                | Object-level permissions    |
| Block Public Access | Prevent accidental exposure |

Used in:
**Amazon S3**
