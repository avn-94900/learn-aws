# AWS KMS Core Concepts

Amazon Key Management Service (AWS KMS) is a fully managed cryptographic service that provides centralized control over encryption keys used to protect your data. Understanding the following core concepts is essential for implementing robust security and encryption strategies in AWS.

- **Fully managed service** (no infrastructure management required)
- **Hardware Security Module (HSM) backed** with FIPS 140-3 Security Level 3 validation
- **Centralized key management** across all AWS services
- **Audit and compliance** with detailed logging via CloudTrail
- **Global service** with regional key storage and management

## 1. KMS Keys (Customer Master Keys - CMKs)

KMS keys are the primary cryptographic resources in AWS KMS used to encrypt and decrypt data.

- **Definition**: Logical representation of a cryptographic key within AWS KMS
- **Key Material**: The actual cryptographic key material (256-bit AES-GCM for symmetric keys)
- **Never Exported**: Key material never leaves AWS KMS unencrypted
- **Regional**: Keys are created and stored in specific AWS regions
- **Key ID**: Unique identifier for each KMS key within a region

## 2. Key Types

AWS KMS supports different types of keys for various cryptographic operations.

### Symmetric Keys
- **Definition**: Single key used for both encryption and decryption
- **Algorithm**: 256-bit AES-GCM encryption (128-bit SM4 in China regions)
- **Use Cases**: Envelope encryption, server-side encryption for AWS services
- **Performance**: Most efficient for bulk data encryption
- **Default**: Created by default when you create a KMS key

### Asymmetric Keys
- **Definition**: Key pairs with separate public and private keys
- **Algorithms**: RSA (2048, 3072, 4096-bit), ECC (P-256, P-384, P-521, secp256k1)
- **Use Cases**: Digital signatures, public key encryption, SSL/TLS
- **Public Key**: Can be downloaded and used outside AWS
- **Private Key**: Never leaves AWS KMS

### HMAC Keys
- **Definition**: Keys used for Hash-based Message Authentication Code
- **Algorithm**: SHA-224, SHA-256, SHA-384, SHA-512
- **Use Cases**: Message authentication, data integrity verification
- **Size**: 224 to 512 bits depending on the algorithm

## 3. Key Ownership and Management

### Customer Managed Keys
- **Definition**: KMS keys that you create, own, and manage
- **Control**: Full control over key policies, rotation, and lifecycle
- **Billing**: Charged per key per month plus usage
- **Rotation**: Automatic rotation available (annual)
- **Use Cases**: When you need full control over encryption keys

### AWS Managed Keys
- **Definition**: KMS keys created and managed by AWS services
- **Naming**: Follow pattern `aws/service-name` (e.g., `aws/s3`, `aws/rds`)
- **Control**: Limited control - AWS manages policies and rotation
- **Billing**: No monthly fee, only usage charges
- **Rotation**: Automatic rotation every year (cannot be disabled)

### AWS Owned Keys
- **Definition**: Keys owned and managed entirely by AWS
- **Visibility**: Not visible in your AWS account
- **Control**: No customer control or visibility
- **Billing**: No charges to customer
- **Use Cases**: Default encryption for some AWS services

## 4. Key Policies

Key policies are JSON-based resource policies that define permissions for KMS keys.

- **Definition**: Primary method for controlling access to KMS keys
- **Format**: JSON documents using AWS Policy Language
- **Scope**: Apply to specific KMS keys
- **Elements**: Principal, Action, Resource, Condition, Effect
- **Size Limit**: Maximum 32 KB per policy
- **Default Policy**: Created automatically with new customer managed keys

### Sample Key Policy Structure
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "Enable IAM User Permissions",
      "Effect": "Allow",
      "Principal": {"AWS": "arn:aws:iam::123456789012:root"},
      "Action": "kms:*",
      "Resource": "*"
    }
  ]
}
```

## 5. Envelope Encryption

Envelope encryption is a cryptographic practice where data is encrypted using a data key, and the data key itself is encrypted using a KMS key.

- **Definition**: Multi-layer encryption approach for large datasets
- **Process Flow**: 
  1. Generate plaintext data key using KMS
  2. Encrypt your data with the plaintext data key
  3. Encrypt the data key with KMS key (envelope)
  4. Store encrypted data + encrypted data key
- **Benefits**: Improved performance, reduced network traffic to KMS
- **Use Cases**: Client-side encryption, AWS service encryption

## 6. Data Keys

Data keys are encryption keys generated by AWS KMS for use in your applications.

- **Definition**: Symmetric encryption keys generated by AWS KMS
- **Types**: Plaintext data key, Encrypted data key (envelope)
- **Size**: 256-bit (32 bytes) or custom size
- **Lifecycle**: Generated on-demand, not stored in KMS
- **Usage Pattern**: Generate → Use → Destroy plaintext version

## 7. Encryption Context

Encryption context is additional authenticated data (AAD) used in cryptographic operations.

- **Definition**: Set of key-value pairs that represent additional authenticated data
- **Security**: Included in cryptographic operations for integrity
- **Logging**: Recorded in CloudTrail logs for audit purposes
- **Format**: String key-value pairs (non-secret)
- **Validation**: Must match during decryption operations

### Example Encryption Context
```json
{
  "Department": "Finance",
  "Project": "Alpha",
  "Environment": "Production"
}
```

## 8. Key Rotation

Key rotation is the process of replacing cryptographic keys with new ones periodically.

### Automatic Rotation
- **Frequency**: Annual rotation for customer managed keys
- **Process**: AWS generates new key material, keeps old versions
- **Backward Compatibility**: Old versions remain available for decryption
- **Configuration**: Can be enabled/disabled for customer managed keys
- **AWS Managed Keys**: Always enabled, cannot be disabled

### Manual Rotation
- **Process**: Create new KMS key, update applications to use new key
- **Control**: Complete control over timing and process
- **Alias**: Use key aliases to simplify key rotation in applications
- **Migration**: Gradual migration from old to new keys

## 9. Key States

KMS keys transition through different states during their lifecycle.

- **Creating**: Key is being created but not yet available
- **Enabled**: Key is active and available for cryptographic operations
- **Disabled**: Key is inactive, cannot be used for operations
- **Pending Deletion**: Key scheduled for deletion (7-30 day waiting period)
- **Unavailable**: Key temporarily unavailable (rare state)

## 10. Grants

Grants provide a mechanism for programmatic delegation of KMS key permissions.

- **Definition**: Token-based authorization mechanism for KMS keys
- **Temporary**: Can be created and revoked programmatically
- **Delegation**: Allow services to use keys on your behalf
- **Constraints**: Can include encryption context constraints
- **Operations**: Support specific operations like Decrypt, GenerateDataKey

## KMS Key Anatomy
Each KMS key includes the following components:

* **Key ID** – Unique identifier within the region
* **Key ARN** – Amazon Resource Name for the key
* **Key Material** – The actual cryptographic key (never exported)
* **Key Spec** – Algorithm and key size specification
* **Key Usage** – ENCRYPT_DECRYPT, SIGN_VERIFY, or GENERATE_VERIFY_MAC
* **Key Origin** – AWS_KMS, EXTERNAL, or AWS_CLOUDHSM
* **Description** – Human-readable description of the key
* **Creation Date** – When the key was created
* **Key State** – Current state of the key

## Key Specifications and Algorithms

### Symmetric Key Specifications
* **SYMMETRIC_DEFAULT** – 256-bit AES-GCM (most common)
* **SYMMETRIC_DEFAULT** – 128-bit SM4 (China regions only)

### Asymmetric Key Specifications
* **RSA_2048** – 2048-bit RSA key pair
* **RSA_3072** – 3072-bit RSA key pair  
* **RSA_4096** – 4096-bit RSA key pair
* **ECC_NIST_P256** – 256-bit elliptic curve
* **ECC_NIST_P384** – 384-bit elliptic curve
* **ECC_NIST_P521** – 521-bit elliptic curve
* **ECC_SECG_P256K1** – 256-bit elliptic curve (Bitcoin)

### HMAC Key Specifications
* **HMAC_224** – SHA-224 based HMAC
* **HMAC_256** – SHA-256 based HMAC
* **HMAC_384** – SHA-384 based HMAC
* **HMAC_512** – SHA-512 based HMAC

## Cryptographic Operations

### Encryption Operations
* **Encrypt**: Encrypt up to 4 KB of data directly with KMS key
* **Decrypt**: Decrypt ciphertext that was encrypted with KMS key
* **GenerateDataKey**: Generate data key for envelope encryption
* **GenerateDataKeyWithoutPlaintext**: Generate only encrypted data key
* **ReEncrypt**: Re-encrypt data under different KMS key

### Signing Operations (Asymmetric Keys)
* **Sign**: Create digital signature for message
* **Verify**: Verify digital signature authenticity
* **GetPublicKey**: Retrieve public key for verification

### HMAC Operations
* **GenerateMac**: Generate HMAC tag for message
* **VerifyMac**: Verify HMAC tag authenticity

### Audit and Logging
* **CloudTrail Integration**: All KMS API calls logged

## Error Handling and Troubleshooting

### Common Error Scenarios
* **AccessDenied**: Insufficient permissions for key operations
* **KeyUnavailable**: Key in disabled or pending deletion state
* **InvalidKeyUsage**: Using key for unsupported operation type
* **ThrottlingException**: Request rate exceeded service limits

### Troubleshooting Steps
* **Check Key State**: Verify key is in enabled state
* **Review Policies**: Validate IAM and key policies
* **Verify Permissions**: Ensure correct permissions for operation
* **Check Encryption Context**: Validate context matches original encryption

### Performance Optimization
* **Data Key Caching**: Cache data keys to reduce KMS calls
* **Batch Operations**: Combine multiple operations when possible
* **Regional Optimization**: Use keys in same region as resources
* **Service Limits**: Monitor and plan for KMS service quotas

### KMS Service Implementation
```java
import software.amazon.awssdk.services.kms.KmsClient;
import software.amazon.awssdk.services.kms.model.*;
import software.amazon.awssdk.core.SdkBytes;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.util.Base64;
import java.util.Map;

@Service
public class KmsEncryptionService {

    private final KmsClient kmsClient;
    private final String keyId = "arn:aws:kms:ap-south-1:123456789012:key/12345678-1234-1234-1234-123456789012";

    public KmsEncryptionService(KmsClient kmsClient) {
        this.kmsClient = kmsClient;
    }

    // Direct encryption (up to 4KB)
    public String encryptData(String plaintext, Map<String, String> encryptionContext) {
        try {
            EncryptRequest request = EncryptRequest.builder()
                    .keyId(keyId)
                    .plaintext(SdkBytes.fromString(plaintext, StandardCharsets.UTF_8))
                    .encryptionContext(encryptionContext)
                    .build();

            EncryptResponse response = kmsClient.encrypt(request);
            return Base64.getEncoder().encodeToString(response.ciphertextBlob().asByteArray());

        } catch (Exception e) {
            throw new RuntimeException("Failed to encrypt data", e);
        }
    }

    // Direct decryption
    public String decryptData(String encryptedData, Map<String, String> encryptionContext) {
        try {
            byte[] ciphertextBlob = Base64.getDecoder().decode(encryptedData);
            
            DecryptRequest request = DecryptRequest.builder()
                    .ciphertextBlob(SdkBytes.fromByteArray(ciphertextBlob))
                    .encryptionContext(encryptionContext)
                    .build();

            DecryptResponse response = kmsClient.decrypt(request);
            return response.plaintext().asString(StandardCharsets.UTF_8);

        } catch (Exception e) {
            throw new RuntimeException("Failed to decrypt data", e);
        }
    }

    // Generate data key for envelope encryption
    public DataKeyResult generateDataKey(Map<String, String> encryptionContext) {
        try {
            GenerateDataKeyRequest request = GenerateDataKeyRequest.builder()
                    .keyId(keyId)
                    .keySpec(DataKeySpec.AES_256)
                    .encryptionContext(encryptionContext)
                    .build();

            GenerateDataKeyResponse response = kmsClient.generateDataKey(request);
            
            return new DataKeyResult(
                    response.plaintextKey().asByteArray(),
                    Base64.getEncoder().encodeToString(response.ciphertextBlob().asByteArray())
            );

        } catch (Exception e) {
            throw new RuntimeException("Failed to generate data key", e);
        }
    }

    // Decrypt data key
    public byte[] decryptDataKey(String encryptedDataKey, Map<String, String> encryptionContext) {
        try {
            byte[] ciphertextBlob = Base64.getDecoder().decode(encryptedDataKey);
            
            DecryptRequest request = DecryptRequest.builder()
                    .ciphertextBlob(SdkBytes.fromByteArray(ciphertextBlob))
                    .encryptionContext(encryptionContext)
                    .build();

            DecryptResponse response = kmsClient.decrypt(request);
            return response.plaintext().asByteArray();

        } catch (Exception e) {
            throw new RuntimeException("Failed to decrypt data key", e);
        }
    }

    // Create KMS key
    public String createKey(String description, String keyUsage) {
        try {
            CreateKeyRequest request = CreateKeyRequest.builder()
                    .description(description)
                    .keyUsage(KeyUsageType.fromValue(keyUsage))
                    .keySpec(KeySpec.SYMMETRIC_DEFAULT)
                    .origin(OriginType.AWS_KMS)
                    .build();

            CreateKeyResponse response = kmsClient.createKey(request);
            return response.keyMetadata().keyId();

        } catch (Exception e) {
            throw new RuntimeException("Failed to create KMS key", e);
        }
    }

    // Enable key rotation
    public void enableKeyRotation(String keyId) {
        try {
            PutKeyRotationStatusRequest request = PutKeyRotationStatusRequest.builder()
                    .keyId(keyId)
                    .keyRotationEnabled(true)
                    .build();

            kmsClient.putKeyRotationStatus(request);
            System.out.println("Key rotation enabled for: " + keyId);

        } catch (Exception e) {
            throw new RuntimeException("Failed to enable key rotation", e);
        }
    }

    // Get key information
    public KeyMetadata getKeyInfo(String keyId) {
        try {
            DescribeKeyRequest request = DescribeKeyRequest.builder()
                    .keyId(keyId)
                    .build();

            DescribeKeyResponse response = kmsClient.describeKey(request);
            return response.keyMetadata();

        } catch (Exception e) {
            throw new RuntimeException("Failed to describe key", e);
        }
    }

    // Create grant for service delegation
    public String createGrant(String keyId, String granteePrincipal, String... operations) {
        try {
            CreateGrantRequest request = CreateGrantRequest.builder()
                    .keyId(keyId)
                    .granteePrincipal(granteePrincipal)
                    .operations(operations)
                    .build();

            CreateGrantResponse response = kmsClient.createGrant(request);
            return response.grantId();

        } catch (Exception e) {
            throw new RuntimeException("Failed to create grant", e);
        }
    }

    record DataKeyResult(byte[] plaintextKey, String encryptedKey) {}
}
```

### Envelope Encryption Service
```java
import org.springframework.stereotype.Service;
import javax.crypto.Cipher;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.util.Arrays;
import java.util.Base64;
import java.util.Map;

@Service
public class EnvelopeEncryptionService {

    private final KmsEncryptionService kmsService;
    private static final String AES_GCM = "AES/GCM/NoPadding";
    private static final int GCM_IV_LENGTH = 12;
    private static final int GCM_TAG_LENGTH = 16;

    public EnvelopeEncryptionService(KmsEncryptionService kmsService) {
        this.kmsService = kmsService;
    }

    // Encrypt large data using envelope encryption
    public EncryptedData encryptLargeData(byte[] data, Map<String, String> encryptionContext) {
        try {
            // Generate data key
            KmsEncryptionService.DataKeyResult dataKey = kmsService.generateDataKey(encryptionContext);
            
            // Generate IV for AES-GCM
            byte[] iv = new byte[GCM_IV_LENGTH];
            new SecureRandom().nextBytes(iv);
            
            // Encrypt data with data key
            Cipher cipher = Cipher.getInstance(AES_GCM);
            SecretKeySpec keySpec = new SecretKeySpec(dataKey.plaintextKey(), "AES");
            GCMParameterSpec gcmSpec = new GCMParameterSpec(GCM_TAG_LENGTH * 8, iv);
            cipher.init(Cipher.ENCRYPT_MODE, keySpec, gcmSpec);
            
            byte[] encryptedData = cipher.doFinal(data);
            
            // Clear plaintext data key from memory
            Arrays.fill(dataKey.plaintextKey(), (byte) 0);
            
            return new EncryptedData(
                    Base64.getEncoder().encodeToString(encryptedData),
                    Base64.getEncoder().encodeToString(iv),
                    dataKey.encryptedKey()
            );

        } catch (Exception e) {
            throw new RuntimeException("Failed to encrypt large data", e);
        }
    }

    // Decrypt large data using envelope encryption
    public byte[] decryptLargeData(EncryptedData encryptedData, Map<String, String> encryptionContext) {
        try {
            // Decrypt data key
            byte[] dataKey = kmsService.decryptDataKey(encryptedData.encryptedDataKey(), encryptionContext);
            
            // Decrypt data
            Cipher cipher = Cipher.getInstance(AES_GCM);
            SecretKeySpec keySpec = new SecretKeySpec(dataKey, "AES");
            byte[] iv = Base64.getDecoder().decode(encryptedData.iv());
            GCMParameterSpec gcmSpec = new GCMParameterSpec(GCM_TAG_LENGTH * 8, iv);
            cipher.init(Cipher.DECRYPT_MODE, keySpec, gcmSpec);
            
            byte[] encryptedBytes = Base64.getDecoder().decode(encryptedData.ciphertext());
            byte[] decryptedData = cipher.doFinal(encryptedBytes);
            
            // Clear data key from memory
            Arrays.fill(dataKey, (byte) 0);
            
            return decryptedData;

        } catch (Exception e) {
            throw new RuntimeException("Failed to decrypt large data", e);
        }
    }

    record EncryptedData(String ciphertext, String iv, String encryptedDataKey) {}
}
```

### REST Controller Example
```java
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.util.Map;

@RestController
@RequestMapping("/api/encryption")
public class EncryptionController {

    private final KmsEncryptionService kmsService;
    private final EnvelopeEncryptionService envelopeService;

    public EncryptionController(KmsEncryptionService kmsService, 
                              EnvelopeEncryptionService envelopeService) {
        this.kmsService = kmsService;
        this.envelopeService = envelopeService;
    }

    @PostMapping("/encrypt-text")
    public ResponseEntity<Map<String, String>> encryptText(
            @RequestBody EncryptionRequest request) {
        
        Map<String, String> context = Map.of(
            "department", request.department(),
            "environment", "production"
        );
        
        String encrypted = kmsService.encryptData(request.plaintext(), context);
        
        return ResponseEntity.ok(Map.of(
            "encrypted", encrypted,
            "context", context.toString()
        ));
    }

    @PostMapping("/decrypt-text")
    public ResponseEntity<Map<String, String>> decryptText(
            @RequestBody DecryptionRequest request) {
        
        String decrypted = kmsService.decryptData(request.ciphertext(), request.context());
        
        return ResponseEntity.ok(Map.of(
            "plaintext", decrypted
        ));
    }

    @PostMapping("/encrypt-file")
    public ResponseEntity<Map<String, Object>> encryptFile(
            @RequestParam("file") MultipartFile file,
            @RequestParam("department") String department) throws IOException {
        
        Map<String, String> context = Map.of(
            "department", department,
            "filename", file.getOriginalFilename(),
            "environment", "production"
        );
        
        EnvelopeEncryptionService.EncryptedData encrypted = 
                envelopeService.encryptLargeData(file.getBytes(), context);
        
        return ResponseEntity.ok(Map.of(
            "encryptedData", encrypted,
            "originalSize", file.getSize(),
            "context", context
        ));
    }

    @PostMapping("/decrypt-file")
    public ResponseEntity<byte[]> decryptFile(
            @RequestBody EnvelopeDecryptionRequest request) {
        
        byte[] decrypted = envelopeService.decryptLargeData(
                new EnvelopeEncryptionService.EncryptedData(
                        request.ciphertext(),
                        request.iv(),
                        request.encryptedDataKey()
                ),
                request.context()
        );
        
        return ResponseEntity.ok()
                .header("Content-Type", "application/octet-stream")
                .body(decrypted);
    }

    @PostMapping("/create-key")
    public ResponseEntity<Map<String, String>> createKey(
            @RequestBody CreateKeyRequest request) {
        
        String keyId = kmsService.createKey(request.description(), request.keyUsage());
        
        return ResponseEntity.ok(Map.of(
            "keyId", keyId,
            "message", "KMS key created successfully"
        ));
    }

    @GetMapping("/key-info/{keyId}")
    public ResponseEntity<KeyMetadata> getKeyInfo(@PathVariable String keyId) {
        KeyMetadata metadata = kmsService.getKeyInfo(keyId);
        return ResponseEntity.ok(metadata);
    }

    record EncryptionRequest(String plaintext, String department) {}
    record DecryptionRequest(String ciphertext, Map<String, String> context) {}
    record CreateKeyRequest(String description, String keyUsage) {}
    record EnvelopeDecryptionRequest(String ciphertext, String iv, 
                                   String encryptedDataKey, Map<String, String> context) {}
}
```

### Configuration
```java
import software.amazon.awssdk.auth.credentials.DefaultCredentialsProvider;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.services.kms.KmsClient;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class KmsConfig {

    @Bean
    public KmsClient kmsClient() {
        return KmsClient.builder()
                .region(Region.AP_SOUTH_1)
                .credentialsProvider(DefaultCredentialsProvider.create())
                .build();
    }
}
```
