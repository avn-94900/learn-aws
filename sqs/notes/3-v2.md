## 1. SQS Fundamentals & Core Concepts

### What is Amazon SQS?
- **Definition**: Fully managed message queuing service for decoupling and scaling microservices
- **Purpose**: Enables asynchronous communication between distributed system components
- **Key Benefits**: High availability, durability, scalability, cost-effective

### SQS Queue Types
- **Standard Queue**: 
  - Nearly unlimited throughput
  - At-least-once delivery
  - Best-effort ordering
  - May have duplicate messages
- **FIFO Queue**: 
  - First-In-First-Out delivery
  - Exactly-once processing
  - Limited to 300 TPS (3000 with batching)
  - Supports message grouping

### Core SQS Concepts
- **Message**: Data payload (up to 256 KB)
- **Queue**: Named storage for messages
- **Producer**: Application that sends messages
- **Consumer**: Application that receives/processes messages
- **Visibility Timeout**: Time message is invisible after being received
- **Dead Letter Queue (DLQ)**: Queue for failed messages
- **Long Polling**: Reduces empty responses and costs

### Strategies for Handling Poison Messages

```java
@Service
public class PoisonMessageHandler {
    
    @SqsListener("${sqs.main.queue}")
    public void processMessage(String message, 
                              @Header("MessageId") String messageId,
                              @Header("ApproximateReceiveCount") String receiveCount) {
        
        int attempts = Integer.parseInt(receiveCount);
        
        try {
            // Validate message format first
            if (!isValidMessageFormat(message)) {
                log.error("Invalid message format, sending to DLQ: {}", messageId);
                throw new PoisonMessageException("Invalid message format");
            }
            
            // Process message
            processBusinessLogic(message);
            
        } catch (PoisonMessageException e) {
            // Don't retry poison messages
            log.error("Poison message detected: {}", messageId);
            throw e;
            
        } catch (TransientException e) {
            // Retry transient failures
            if (attempts < 3) {
                log.warn("Transient error, attempt {}: {}", attempts, e.getMessage());
                throw e;
            } else {
                log.error("Max retries exceeded for message: {}", messageId);
                throw new MaxRetriesExceededException(e);
            }
            
        } catch (Exception e) {
            // Handle unexpected errors
            log.error("Unexpected error processing message {}: {}", messageId, e.getMessage());
            throw e;
        }
    }
    
    private boolean isValidMessageFormat(String message) {
        try {
            JsonNode jsonNode = objectMapper.readTree(message);
            return jsonNode.has("orderId") && jsonNode.has("customerId");
        } catch (Exception e) {
            return false;
        }
    }
}
```

### Implementing Exponential Backoff

```java
@Service
public class ExponentialBackoffProcessor {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    @SqsListener("${sqs.main.queue}")
    public void processWithBackoff(String message, 
                                  @Header("MessageId") String messageId,
                                  @Header("ApproximateReceiveCount") String receiveCount) {
        
        int attempts = Integer.parseInt(receiveCount);
        String backoffKey = "backoff:" + messageId;
        
        try {
            // Check if message is in backoff period
            if (isInBackoffPeriod(backoffKey, attempts)) {
                log.info("Message {} still in backoff period", messageId);
                throw new BackoffException("Message in backoff period");
            }
            
            // Process message
            processMessage(message);
            
            // Clear backoff on success
            redisTemplate.delete(backoffKey);
            
        } catch (BackoffException e) {
            throw e; // Don't process, let it return to queue
            
        } catch (Exception e) {
            // Set backoff period
            setBackoffPeriod(backoffKey, attempts);
            throw e;
        }
    }
    
    private boolean isInBackoffPeriod(String key, int attempts) {
        Long backoffExpiry = (Long) redisTemplate.opsForValue().get(key);
        if (backoffExpiry == null) return false;
        
        return System.currentTimeMillis() < backoffExpiry;
    }
    
    private void setBackoffPeriod(String key, int attempts) {
        // Exponential backoff: 2^attempts seconds
        long backoffSeconds = (long) Math.pow(2, attempts);
        long expiryTime = System.currentTimeMillis() + (backoffSeconds * 1000);
        
        redisTemplate.opsForValue().set(key, expiryTime, 
            Duration.ofSeconds(backoffSeconds * 2));
    }
}
```

### Implementing Idempotent Message Processing

```java
@Service
public class IdempotentMessageProcessor {
    
    private final RedisTemplate<String, String> redisTemplate;
    private final TransactionTemplate transactionTemplate;
    
    @SqsListener("${sqs.orders.queue}")
    @Transactional
    public void processOrderMessage(String orderMessage, 
                                   @Header("MessageId") String messageId) {
        
        String idempotencyKey = extractIdempotencyKey(orderMessage);
        
        // Check if already processed using idempotency key
        if (isAlreadyProcessed(idempotencyKey)) {
            log.info("Order {} already processed, returning cached result", idempotencyKey);
            return;
        }
        
        // Use distributed lock to prevent concurrent processing
        String lockKey = "lock:order:" + idempotencyKey;
        Boolean lockAcquired = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "locked", Duration.ofMinutes(5));
        
        if (!lockAcquired) {
            log.warn("Could not acquire lock for order {}, skipping", idempotencyKey);
            return;
        }
        
        try {
            // Double-check after acquiring lock
            if (isAlreadyProcessed(idempotencyKey)) {
                return;
            }
            
            // Process order within transaction
            transactionTemplate.execute(status -> {
                Order order = parseOrder(orderMessage);
                orderService.createOrder(order);
                
                // Mark as processed atomically with business logic
                markAsProcessed(idempotencyKey, messageId);
                return null;
            });
            
        } finally {
            redisTemplate.delete(lockKey);
        }
    }
    
    private String extractIdempotencyKey(String message) {
        // Extract business identifier (orderId, transactionId, etc.)
        JsonNode jsonNode = objectMapper.readTree(message);
        return jsonNode.get("orderId").asText();
    }
    
    private boolean isAlreadyProcessed(String idempotencyKey) {
        return redisTemplate.hasKey("processed:" + idempotencyKey);
    }
    
    private void markAsProcessed(String idempotencyKey, String messageId) {
        String key = "processed:" + idempotencyKey;
        redisTemplate.opsForValue().set(key, messageId, Duration.ofHours(24));
    }
}
```

### Handling Duplicate Messages in Standard Queues

```java
@Service
public class DuplicateMessageHandler {
    
    private final MessageTrackingRepository trackingRepository;
    
    @SqsListener("${sqs.standard.queue}")
    public void handleMessage(String message, 
                             @Header("MessageId") String messageId,
                             @Header("MD5OfBody") String messageHash) {
        
        // Strategy 1: Use SQS MessageId for deduplication
        if (trackingRepository.existsByMessageId(messageId)) {
            log.info("Duplicate message detected by ID: {}", messageId);
            return;
        }
        
        // Strategy 2: Use message content hash for deduplication
        if (trackingRepository.existsByContentHash(messageHash)) {
            log.info("Duplicate message detected by content hash: {}", messageHash);
            return;
        }
        
        // Strategy 3: Use business identifier from message content
        String businessId = extractBusinessId(message);
        if (trackingRepository.existsByBusinessId(businessId)) {
            log.info("Duplicate message detected by business ID: {}", businessId);
            return;
        }
        
        try {
            // Process message
            processMessage(message);
            
            // Track successful processing
            MessageTrack track = new MessageTrack(messageId, messageHash, businessId);
            trackingRepository.save(track);
            
        } catch (Exception e) {
            log.error("Failed to process message {}: {}", messageId, e.getMessage());
            throw e;
        }
    }
    
    // Cleanup old tracking records
    @Scheduled(fixedRate = 3600000) // Every hour
    public void cleanupOldTrackingRecords() {
        LocalDateTime cutoff = LocalDateTime.now().minusHours(24);
        trackingRepository.deleteByCreatedTimeBefore(cutoff);
    }
}
```

```java
            .withQueueUrl(queueUrl)
            .withMessageBody(objectMapper.writeValueAsString(event))
            .withMessageGroupId(event.getCustomerId())
            // Don't set MessageDeduplicationId - let SQS use content-based deduplication
            .withMessageAttributes(createMessageAttributes(event));
        
        SendMessageResult result = amazonSQS.sendMessage(request);
        log.info("Sent message with content-based deduplication: {}", result.getMessageId());
    }
    
    public void sendMessageWithCustomDeduplication(String queueUrl, OrderEvent event) {
        // Custom deduplication ID based on business logic
        String deduplicationId = generateCustomDeduplicationId(event);
        
        SendMessageRequest request = new SendMessageRequest()
            .withQueueUrl(queueUrl)
            .withMessageBody(objectMapper.writeValueAsString(event))
            .withMessageGroupId(event.getCustomerId())
            .withMessageDeduplicationId(deduplicationId)
            .withMessageAttributes(createMessageAttributes(event));
        
        SendMessageResult result = amazonSQS.sendMessage(request);
        log.info("Sent message with custom deduplication ID {}: {}", 
                deduplicationId, result.getMessageId());
    }
    
    private String generateCustomDeduplicationId(OrderEvent event) {
        // Create deduplication ID based on business logic
        // This ensures messages with same business meaning are deduplicated
        return DigestUtils.sha256Hex(
            event.getOrderId() + 
            event.getCustomerId() + 
            event.getEventType() +
            event.getTimestamp().toEpochSecond()
        );
    }
}
```

## 8. Performance Optimization & Monitoring

### Key Metrics to Monitor
- **ApproximateNumberOfMessages**: Messages in queue
- **ApproximateNumberOfMessagesNotVisible**: Messages being processed
- **NumberOfMessagesSent**: Messages sent to queue
- **NumberOfMessagesReceived**: Messages received from queue
- **NumberOfMessagesDeleted**: Successfully processed messages
- **ApproximateAgeOfOldestMessage**: Age of oldest unprocessed message
- **NumberOfMessagesInDLQ**: Messages in dead letter queue

### Scaling Strategies
- Horizontal scaling: Multiple consumer instances
- Vertical scaling: Increase processing power per consumer
- Auto-scaling: Scale based on queue depth
- Batch processing: Process multiple messages together
- Long polling: Reduce empty responses and API calls
